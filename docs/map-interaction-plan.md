# خريطة النبات: خطة الرسم والتفاعل

تاريخ القرار: 2026-11-23. نطاق هذا الملف: `src/map.js` و`src/map.css` فقط؛ بطاقة المصادر، استقبال UUID، استيراد Excel، وحالات البيانات ينفذها المكوّن المضيف.

## المهمة والقالب

المهمة الأساسية هي استعراض المناطق التي ورد فيها النبات الحالي في المصادر وفتح أدلة المنطقة. المكوّن عربي RTL داخل بطاقة محتوى، وليس صفحة أطلس أو بحث مستقلة. أقرب قالب هو `UDS-TPL-CONTENT` (صفحة المحتوى)؛ لا يوجد قالب خريطة منشور في السجل، لذا المطابقة التفصيلية للخريطة `NEEDS-VERIFICATION`.

## المكونات والاستثناء

دُرس المكوّن الرسمي `Charts`، الذي يسجل أنواع pie وline وbar؛ لا يحتوي رسم مضلعات إدارية. لذلك يُستخدم SVG مخصص بالحدود الموجودة في `regions.v1.json`، دون تغيير شكل المملكة أو إعادة إسقاطها. المضلعات أزرار SVG مسماة مع تشغيل Enter وSpace؛ توفير أزرار HTML مكافئة بحجم لا يقل عن `--uds-touch-target` في المكوّن المضيف مطلوب للوصول إلى المناطق الصغيرة على اللمس. لا تُختلق واجهات برمجية لحزمة UDS.

القواعد المتأثرة بالاستثناء: `UDS-GOV-006` و`UDS-COMP-CHART-001` و`UDS-COMP-BUTTON-001` و`UDS-A11Y-004` و`UDS-LAYOUT-014`. لا يُدعى اكتمال الامتثال قبل فحص البديل النصي في المضيف. التحديد والتوثيق لهما أسماء وصول ونصوص مكافئة خارج الرسم؛ لا نعتمد على اللون وحده.

## القواعد المطبقة

`UDS-COLOR-001,002,006,007,008,009,012`، `UDS-TYPO-001,003,009`، `UDS-LAYOUT-006,013,014`، `UDS-RTL-001,005`، `UDS-A11Y-001,002,003,004,005,022,024`، `UDS-COMP-CHART-001`، `UDS-CONTENT-001,005`، `UDS-DEV-008`، `UDS-QUALITY-001`.

## البنية والهوية

- حاوية رسم واحدة تنشئ SVG للمناطق الثلاث عشرة؛ الأسماء زخرفية داخل الرسم بينما تسمية المضلع قابلة للقراءة المساعدة.
- بلا شبكة خلفية أو علامات مركزية توحي بإحداثيات رصد. لا تُحرّك المضلعات أو تُعكس جغرافيًا مع RTL.
- جميع ألوان الواجهة وخطوطها ومسافاتها من aliases المنشورة في `uds-tokens.css`.
- إحداثيات المسارات والأسماء وأبعاد viewBox بيانات رسم، وليست مقاسات واجهة بديلة عن tokens.
- عند عرض الحاوية بأقل من 600px، تُخفى التسميات المزدحمة، ويُعتمد على أسماء المناطق والأزرار المكافئة في المضيف. لا خطوط إرشاد متشابكة ولا إزاحة للأسماء حول الخريطة.
- لون محايد للمناطق غير الموثقة، وأخضر داكن للمناطق ذات الأدلة. لا تعني المنطقة المحايدة نفي وجود النبات.

## الحركة

الحركة المطلوبة من المستخدم تقتصر على تغير اللون والعتامة، بلا انتقال جغرافي أو نبض مستمر. مدة 180ms قرار خاص بالمشروع وليست token أو قاعدة رسمية. تميّز قاعدة `UDS-DEV-008` بين قرار المشروع وبين الادعاء بأنه رسمي؛ المرجع العام لا ينشر مددًا أو easing معتمدة. توقف `prefers-reduced-motion` هذه الانتقالات. استعادة المصادر الرسمية المباشرة للرسوم والأيقونات في 2026-11-23 انتهت بمهلة اتصال؛ التحقق من تحديثها ما زال `NEEDS-VERIFICATION`، واستُخدم السجل المدقق الموجود بالمشروع.

## عقد التكامل

```js
mountMap(container, regions, {
  onRegionEnter(id, event),
  onRegionLeave(id, event),
  onRegionSelect(id, event),
  onRegionFocus(id, event),
})
// => { update({ documented: Set<string>, selected: string | null }), destroy() }
```

لا يستورد `map.js` CSS عالميًا؛ يضم المضيف محتوى `map.css` داخل Shadow DOM الخاص به. كل نسخة لها عناصرها ومعرفاتها المستقلة. `destroy()` يزيل مراقب الحجم والمستمعين والرسم المملوك للمكوّن فقط. `update()` يغير الحالة دون إعادة إنشاء هندسة الخريطة.

المناطق ذات الأدلة فقط تستقبل التركيز وفتح المصادر. عند تغيير UUID يغلق المضيف البطاقة ويحدّث `documented` و`selected`. لا يجلب الرسم بيانات ولا يقرر صحة الأدلة.

## خطة التحقق

فحص بناء JavaScript، وفحص UDS الساكن، ثم مراجعة داخل المضيف: عرض الهاتف/اللوحي/الحاسوب، عدم قص الخريطة، اتجاه RTL، التباين المحسوب، وصول لوحة المفاتيح، تبادل hover بين المنطقة وبطاقة المصدر، المس، تقليل الحركة، تعدد النسخ، إزالة المكوّن، وتغيير UUID أثناء طلب جار. فحوص المضيف خارج ملكية ملفات هذا الجزء ويجب تسجيل نتيجتها في تقرير التسليم العام.

## نتائج التحقق من جزء الرسم

- اجتاز `node --check src/map.js` الفحص النحوي.
- فحص `python3 tools/uds-compliance/uds_compliance.py src/map.css`: ‏PASS 1، FAIL 0، WARNING 0. هذا الفحص لا ينفّذ JavaScript ولا يثبت صحة الواجهة المولّدة أو مطابقة كل قواعد الإتاحة.
- التباين المحسوب من قيم tokens: النص على المنطقة المحايدة 14.74:1، الأبيض على المنطقة ذات المصادر 6.60:1، الأبيض على المنطقة المحددة 10.81:1، الحد على المنطقة المحايدة 6.31:1، وإطار التركيز الداكن على هالته البيضاء 15.42:1.
- فحص إحداثيات مراكز التسميات مقابل مسارات المضلعات بقاعدة even-odd: جميع التسميات الثلاث عشرة تقع داخل مناطقها. لا يثبت هذا الفحص عدم تداخل عرض النصوص في المتصفح.
- تعذّر اختبار Chromium المحلي قبل إنشاء الصفحة بسبب `socket() failed: Operation not permitted` من البيئة. لم تُختبر حركة المؤشر أو لوحة المفاتيح أو إعادة التدفق في متصفح بهذه المحاولة؛ تظل مطلوبة في فحص المضيف النهائي.
- حالة جزء الرسم قبل فحص المضيف: **PARTIALLY COMPLIANT**. يلزم التأكد من الأزرار النصية المكافئة ذات أهداف 44px ومن الاختبارات اليدوية المذكورة أعلاه. لا يوجد ادعاء امتثال كامل اعتمادًا على الفحص الساكن.
