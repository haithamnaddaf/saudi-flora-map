# دبابيس مواضع النبات — خطة تنفيذ

التاريخ: 2026-11-24. النطاق: `src/map.js` و`src/map.css` واختبارات الرسم فقط. المهمة: تمييز مواضع الرصد المؤهلة بدبوس أخضر واضح، وفتح مصدر الموضع نفسه بالمؤشر أو اللمس أو لوحة المفاتيح. حالات غياب UUID أو الدليل وإخفاء المكوّن يملكها المضيف.

## UDS والقالب والاستثناء

أقرب قالب سياقي `UDS-TPL-CONTENT`؛ قالب الخريطة التفصيلي `NEEDS-VERIFICATION`. دُرس Charts الرسمي: أنواعه المسجلة pie/line/bar لا تغطي جغرافيا المملكة أو علامة ذات طرف مربوط بإحداثية. يستمر استثناء SVG الجغرافي الموثق: رمز الدبوس جزء من طبقة الرسم المخصصة، وليس ادعاء أنه أيقونة رسمية منشورة. لا نضيف حزمة أيقونات أو نفترض API غير موثق.

القواعد: `UDS-GOV-006`، `UDS-COMP-CHART-001`، `UDS-COLOR-006,008,009`، `UDS-TYPO-001,003`، `UDS-LAYOUT-014,016`، `UDS-RTL-001,005`، `UDS-A11Y-002–005,022,024`، `UDS-DEV-008`. تبقى بدائل HTML للمواقع والمناطق في المضيف.

## البنية والسلوك

- تبقى علامة الموضع `g[data-point]` زر SVG مسمى بالعربية. يظل Tab/Enter/Space والأسهم وعقد الأحداث كما هو.
- يرسم مسار الدبوس رأسًا واضحًا وطرفًا عند `(0,0)` في إطار العلامة. يُنقل هذا الإطار إلى الإسقاط الحالي للإحداثية الأصلية، بلا تحويل إلى مركز منطقة أو محافظة، وبلا تغيير حدود أو أبعاد الخريطة.
- حجم الرمز 24px في المكوّن الضيق و32px في الواسع من aliases المسافات المدققة؛ حد الانتقال 600px. منطقة اللمس 44×44px مستقلة وغير مرئية. مقاسات المسار الداخلية هندسة متجهية، وليست tokens تصميم جديدة.
- هالة فاتحة ساكنة للمواضع، وتوهج إضافي قصير عند hover/focus/selected، ثم حالة ثابتة. لا نبض متكرر ولا مؤقتات حركة أو حلقات رسم. تعطل `prefers-reduced-motion` الانتقال الزخرفي، ويبقى التركيز واضحًا.
- الألوان والأحجام والمسافات من `uds-tokens.css`. هندسة الخريطة لا تنعكس مع RTL، والنص العربي لا يتغير.
- يحسب منع تداخل التسميات كامل جسم الدبوس فوق طرفه وهالته، وتُحاذى تسمية الموضع قرب رأسه. تبقى الإحداثية ونقطة إرساء البطاقة عند الطرف دون إزاحة أثناء التفاعل أو التكبير.
- تظل كل زخارف الدبوس `aria-hidden` وغير معترضة للمؤشر؛ لا معرفات SVG مشتركة بين النسخ. لا تغيير لسياسة البيانات أو لقائمة المواضع الأصلية.

## التحقق

اختبارات موجهة لهندسة الطرف وموقعه في إحداثيات العميل، وثباته عند hover/focus/selected والتكبير/التصغير وإعادة الضبط، وحفظ البيانات والمعرفات والتركيز، ومنطقة اللمس والتصادم والتنظيف وتعدد النسخ. تشغيل فحص JavaScript وفحص UDS الساكن. تبقى مراجعة الخط المحمل والتوهج الحقيقي والتباين الفعلي والحواف داخل المتصفح في تحقق المضيف، ولا يُدّعى امتثال كامل من الاختبارات الساكنة.

مرجع الحركة: [W3C — Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html). مدد الانتقال وشفافيته قرارات للمشروع وليست قيمًا رسمية منشورة من UDS.
