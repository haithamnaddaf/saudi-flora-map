# عقد دمج خريطة النبات مع سوار

هذا عقد للمكوّن المستقل في الإصدار **0.5.0**. طريقة الدمج المعتمدة `isolated`: Web Component داخل Shadow DOM، دون iframe. لا يتضمن هذا العمل تغييرًا في مستودع سوار أو نشرًا فيه. يمرر المضيف UUID المدخل الذي يعرضه بالفعل؛ المكوّن لا يقرأ أسماء النباتات من الصفحة ولا يستنتج المعرّف منها. مطابقة أسماء الأماكن عملية مستقلة عن هوية النبات. الخريطة التنبؤية مشروع منفصل لاحقًا، ولا تدخل في هذا العقد.

## تدفق العرض

1. تُحمّل صفحة المضيف ملف المكوّن مرة واحدة.
2. بعد ظهور نتيجة النبات من الباك إند، يُمرر UUID الأصلي إلى `setPlant` أو السمة `uuid`.
3. يجلب المكوّن ملف هذا UUID وملف `spatial` الموازي إن وجد وحدود المحافظات والمناطق المشتركة. لا يحتاج إلى فهرس البحث. يطابق اسم المكان بالمحافظة إذا أمكن، وإلا بالمنطقة المذكورة في المصدر. غياب ملف المشاهدات لا يسمح باستعمال اسم مشتق قديم بدلًا من الاسم الأصلي؛ تظل الأدلة الكتابية أو النصية المستقلة قابلة للمطابقة.
4. تُغلق بطاقة النبات السابق ويُزال تظليله وتُخفى مساحة الخريطة أثناء تحميل المعرّف الجديد. الاستجابة المتأخرة لطلب أقدم لا تستبدل النبات الحالي. لا تظهر مساحة الخريطة وأدواتها إلا إذا كان لهذا المدخل دليل يسمح بتظليل محافظة أو منطقة. لا تُرسم دبابيس رصد.
5. تفتح المحافظة أو المنطقة بطاقة عربية قريبة منها، وتوضح مستوى المكان ومصدره. الوصول إلى البطاقة محمي أثناء عبور المؤشر، والنقر يثبتها؛ Escape والإغلاق والخارج يغلقونها. تتيح أزرار الأماكن الوصول نفسه بلوحة المفاتيح واللمس. رابط المشاهدة يخص الشاهد المعروض نفسه، ولا يخلط روابط مشاهدات مجمعة في أماكن أخرى.

الحقول في ملفات هذه الحزمة هي `uuid` و`senseId`. اسم الحقل المقابل في استجابة سوار يجب تأكيده عند تعديل المضيف؛ لا يفترض هذا المستودع أن اسمًا عامًا مثل `id` أو `_id` يحمل القيمة نفسها. المطلوب **القيمة الأصلية المطابقة**، لا توليد UUID جديد أو بناء جدول ربط بالأسماء العربية.

## مثال قابل للدمج

انشر ناتج `npm run build` تحت مسار مستقل مثل `/flora/`، مع إبقاء الملفات التابعة في مكانها:

```html
<script type="module" src="/flora/assets/flora-map.js"></script>
<saudi-flora-map id="plant-distribution"></saudi-flora-map>
```

في نقطة تحديث بطاقة النبات داخل تطبيق المضيف:

```js
async function displayPlantDistribution(uuid, senseId = null) {
  await customElements.whenDefined('saudi-flora-map')
  document.getElementById('plant-distribution').setPlant(uuid, senseId)
}

// مثال من البيانات الحالية:
displayPlantDistribution(
  'f009a176-94e3-4387-b682-0f416bf31afd',
  '68fa181e1bb5ac220afcfd5e'
)
```

هذا اسم دالة مثال، وليس API موجودًا في سوار. يستدعيه المضيف عندما يغيّر النتيجة المعروضة. عند مسح النتيجة:

```js
document.getElementById('plant-distribution').setPlant(null)
```

## الواجهة

| المدخل أو الحدث | المعنى |
| --- | --- |
| `uuid` / `.uuid` | UUID الأصلي؛ المطابقة دقيقة ولا يُحوّل المكوّن حالة حروفه. |
| `sense-id` | معرّف معنى اختياري. الاختلاف يخفي الخريطة ويعرض «غير متوفر». |
| `.setPlant(uuid, senseId = null)` | يحدّث هوية النبات والمعنى معًا. يمسح معنى النبات السابق عند عدم تمريره. |
| `data-base-url` | رابط مجلد البيانات، ويفضل أن يكون مطلقًا مع `/` أخيرة. الافتراضي مجلد `data/` المجاور لمجلد `assets/`. |
| `local-preview` | اشتراك صريح في تعديلات هذا المتصفح؛ يستخدم في المعاينة والإدارة فقط. |
| `.refresh()` | يعيد حساب العرض الحالي من إصدار البيانات المحمّل والتعديلات المحلية المسموح بها. لا يتجاوز ذاكرة التخزين المؤقت للإصدار نفسه. |
| `.mapAvailable` | خاصية للقراءة فقط؛ true عند وجود خريطة قابلة للعرض للـUUID الحالي. تقابلها السمة `data-map-available="true|false"`. |
| `flora-map:state` | حدث يتجاوز Shadow DOM، ويحمل `detail: { uuid, state, mapAvailable }`. الحالات: `loading` ثم `ready` أو `empty` أو `unknown_uuid` أو `sense_mismatch` أو `error`. |

غياب UUID يعرض طلب اختيار نبات دون خريطة. UUID المجهول والمعنى المختلف والنبات المحجوب والدليل النصي دون مكان قابل للرسم تعرض «غير متوفر» دون خريطة أو مفتاح أو أزرار أماكن. تبقى أسباب المراجعة والأدلة في البيانات والتقرير الإداري. فشل التحميل يعرض رسالة قابلة لإعادة المحاولة. هذا الحدث ليس بديلًا عن حالة نجاح بحث سوار؛ هو حالة عرض الخريطة وحدها.

مثال متابعة الحالة، إذا احتاجها المضيف:

```js
document.getElementById('plant-distribution')
  .addEventListener('flora-map:state', event => {
    const { uuid, state, mapAvailable } = event.detail
    // يمكن للمضيف إخفاء القسم المحيط بالخريطة عندما تكون mapAvailable=false.
    // يبقى المكوّن نفسه متصلًا لاستقبال setPlant وإظهار مدخل صالح لاحقًا.
  })
```

## الملفات والتحميل

- يلزم الاحتفاظ بجميع ملفات `dist/assets/` التابعة للمدخل، والخطوط، و`dist/data/`. نقل `flora-map.js` منفردًا يكسر الروابط النسبية.
- تتشارك نسخ المكوّن طلب الحدود والطلبات الجارية. الذاكرة تحتفظ بحد أقصى 48 ملف نبات ناجح؛ الطلبات الفاشلة لا تمنع إعادة المحاولة.
- الرسم SVG واحد لكل نسخة. تغيير النبات يغيّر حالته دون إنشاء iframe أو إعادة بناء كل هندسة المحافظات والمناطق. لا يستدعي العرض خدمة تحويل إحداثيات أو خرائط خارجية.
- CSS المكوّن داخل Shadow DOM. يوجد تعريف مشترك واحد لوجهي خط IBM Plex Sans Arabic. يتوافر بديل نظامي إذا تعذر الخط.
- لا يجلب المكوّن كتاب Excel أو قارئه أو فهرس جميع النباتات عند عرض UUID. هذه الأصول تخص الإدارة أو البحث عند الطلب.
- لا يُنسخ JSON البحث الخام إلى ملفات النشر.

راجع [تقرير التحقق الحالي](named-place-qa-2026-11-24.md) للاختبارات والقياسات المنفذة وحدودها. أحجام الملفات وgzip ليست قياسًا للشبكة أو معدل الإطارات أو وعدًا بزمن استجابة. لا تعمم نتيجة Chrome على Safari أو Firefox دون تنفيذ الاختبار عليهما.

## إصدار بيانات جديد

لتغيير إصدار البيانات دون إعادة بناء واجهة الخريطة، انشر مجلد البيانات الناتج من أداة الإصدار تحت رابط جديد، مثل:

```html
<saudi-flora-map
  uuid="f009a176-94e3-4387-b682-0f416bf31afd"
  data-base-url="https://example.org/flora/releases/2.0.2/">
</saudi-flora-map>
```

الرابط مثال توضيحي ولم يُنشر. تغيير `data-base-url` يفصل مفاتيح التخزين المؤقت ويحمّل الإصدار الجديد. الأفضل اعتماد رابط إصدار ثابت المحتوى، وتحويل المضيف إلى الإصدار المعتمد. الاستعادة تكون بإرجاع الرابط إلى الإصدار السابق. إذا أُعيد استخدام الرابط نفسه يجب إعادة تحميل الصفحة وضبط تخزين HTTP من جهة النشر.

انقل الإصدار كاملًا: `catalog.v2.json`، ومجلدا `plants/` و`spatial/`، و`regions.v1.json` و`governorates.v1.json`، و`BOUNDARIES.txt` و`GOVERNORATE-BOUNDARIES.txt`، وبيان الإصدار. غياب حدود المحافظات أو تلفها خطأ تحميل، وليس طلبًا للرجوع بصمت إلى خريطة قديمة. لا تنقل الملفات المعدلة وحدها بينما يبقى الفهرس أو رقم الإصدار قديمًا. صفحة الإدارة القياسية تقرأ `data/` المجاور لها؛ راجع [خطوات Excel والإصدار](excel-workflow.md) لتحديث نسخة الإدارة أيضًا.

## التوافق مع المضيف

يُفضّل مسار مستقل على الأصل نفسه لتبسيط تحميل البيانات والخطوط. عند الاستضافة على أصل آخر، يلزم أن تسمح إعدادات CORS بتحميل JavaScript والبيانات والخطوط، وأن تتوافق `script-src` و`connect-src` و`font-src` وسياسة أنماط Shadow DOM مع سياسة CSP الفعلية للمضيف. هذه الإعدادات لم تُختبر داخل سوار؛ لا تغيّر السياسة الإنتاجية تلقائيًا لإمرار المكوّن.

لا توجد آلية كتابة عامة إلى الخادم. صفحة الإدارة تعمل محليًا وتصدر ملف التغييرات؛ نقل الإصدار المشترك جزء من نشر الملفات المعتمد. صفحة المعجم لا تحتاج إلى عرض أزرار الإدارة أو تفعيل `local-preview`.

## حالات لا يجوز تجاوزها

- UUID مجهول أو معنى غير مطابق: لا تُعرض خريطة نبات آخر.
- هوية نبات محجوبة أو تصنيف يحتاج مراجعة: لا يكفي استيراد صف `verified` لفتحها.
- مكان نصي دون إسناد إداري موثق: يبقى في البيانات مع مرجعه؛ لا يعرض وحده خريطة فارغة أو تلوينًا تخمينيًا.
- مرجع قيد المراجعة `pending`: محفوظ لكنه لا يلوّن محافظة أو منطقة.
- فشل تحميل الحدود أو البيانات: رسالة وإعادة محاولة؛ ليس حكمًا بغياب النبات.

## القبول قبل الدمج الإنتاجي

على بيئة متصفح مناسبة، نفّذ الاختبارات المتصفحية المعتمدة وراجع اختيار نباتين متشابهَي الاسم، وتغير UUID سريعًا، ومحافظة صغيرة على الجوال، والفرق بين دليل المحافظة ودليل المنطقة العام، والوصول إلى رابط المصدر من لوحة المفاتيح، وإغلاق البطاقة، والتكبير، وقارئ الشاشة العربي، وأثر CSS وCSP الفعليين. راجع أيضًا تعديل اسم مكان من Excel وحذفه وتعليقه. لا يستعمل مسار Sites المقيد خادم Playwright المستقل دون توافقه مع البيئة. النتائج المنفذة فعلًا في [تقرير المراجعة الحالي](named-place-qa-2026-11-24.md)؛ لم يُنفذ قبول إنتاجي داخل سوار ضمن هذا التعديل.

مراجع التصميم التقني: [MDN: دورة حياة Custom Elements](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements)، [W3C: المحتوى عند المرور أو التركيز](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html). مواصفات الهوية والأدلة الخاصة بالمشروع موثقة في [سياسة الأسماء](named-place-policy.md)، و[خطة العرض الحالية](named-place-map-plan.md)، و[تقرير بيانات الأساس](data-build-report.json).

## مصدر المكان في 0.5.0

يستدعي المكوّن `spatialForPlant` للتحقق من تطابق UUID والاسم العلمي والإصدار والمصدر، ثم `coverageByNamedPlace` للمطابقة. الناتج ثلاث قوائم: محافظات، ومناطق مذكورة دون تحديد محافظة، وأدلة غير محسومة. عند وجود دليل عام لمنطقة ودليل مستقل لمحافظة فيها، يبقى كل دليل بمستواه ومصدره؛ تظليل المنطقة لا يثبت أن النبات موثق في جميع محافظاتها.

| نوع الدليل | اسم المكان الذي تعتمد عليه المطابقة |
| --- | --- |
| مشاهدة ذات ملف مرافق صالح | `localityOriginal`، مع الاستعانة بـ`publisherRegionOriginal` عند توفره |
| كتاب أو قائمة أو بطاقة نبات | `record.place` |
| مكان مشاهدة صُحح في Excel، ولا توجد له مشاهدة مرتبطة صالحة | `record.place` فقط مع `verified` و`provenance.placeNameReviewed=true` |

`publisherRegionOriginal` حقل اختياري ينسخ اسم المنطقة الأصلي من `state_province_verbatim` لدى الناشر؛ لا تُنشئه الواجهة من الإحداثيات أو من `record.regionId`. قد يضع المصدر اسم محافظة في هذا الحقل، فتُحفظ عبارته وتطابق وفق الأسماء المعروفة. `governorateOriginal` و`governorateId` القديمان والإحداثيات لا يحددان التظليل الجديد.

تُحفظ الحقول القديمة للتوثيق، ولا تُصحح بيانات المصدر الأصلية تلقائيًا. الوحدات التي تمثل عاصمة منطقة، والأسماء التي لا تتوافر لها حدود محافظة مستقلة، ترجع إلى المنطقة وفق قواعد الأسماء المراجعة. وصف اتجاهي مثل «٤٠ كم شمال الليث» لا يمنح وحده محافظة الليث. راجع [سياسة الأسماء](named-place-policy.md) و[حدود المحافظات](governorate-boundaries.md).

## مراجعة الاسم في Excel

لا يحتاج قالب Excel إلى أعمدة إحداثيات. تضع أداة الاستيراد `provenance.placeNameReviewed=true` عندما تكون الإضافة الجديدة `verified` أو يصحح صف `verified` اسم المكان فعليًا. تحفظ العلامة السابقة عند تغيير الصياغة دون تبديل المرجع، وتسقط عند التعليق أو تغيير بيانات المرجع. إعادة الاستيراد أو تعديل الملخص أو تحويل pending إلى verified وحده لا يمنح مراجعة جديدة لاسم لم يتغير.

تغيير مكان علاقة أو مرجعها يبطل ارتباط تفاصيل المشاهدة القديمة بها. ينقل أمر إعداد الإصدار التفاصيل التي ما زالت مرتبطة بالمصدر والمكان نفسيهما، ويحفظ `publisherRegionOriginal` وعلامة المراجعة عند انطباق شروطهما. لا يلزم إعادة جمع النباتات أو تغيير UUID لتحديث أسماء الأماكن والمراجع. تفاصيل العمل في [دليل Excel](excel-workflow.md).

## إتاحة العرض

تخفي `mapAvailable=false` مساحة الرسم داخليًا تلقائيًا. إذا أضاف تطبيق سوار عنوانًا أو إطارًا خارجيًا، يستعمل الحالة نفسها لإخفائه أيضًا، مع إبقاء المكوّن متصلًا لاستقبال UUID صالح لاحقًا. لا يُفترض أن لكل UUID خريطة، ولا أن وجود اسم علمي صحيح يثبت موقعًا سعوديًا. «غير متوفر» تصف إتاحة الخريطة الحالية ولا تنفي وجود النبات في المملكة.

الحركات قصيرة للتحديد وفتح البطاقة، وتُلغى عند طلب تقليل الحركة. لا دبابيس ولا نبض مستمر في العرض الحالي. التظليل يعتمد على أسماء المصادر، والخريطة التنبؤية ليست جزءًا من التنفيذ أو عقد البيانات الحالي.
