# عقد دمج خريطة النبات مع سوار

هذا عقد للمكوّن المستقل في الإصدار 0.2.0. لا يتضمن تغييرًا في مستودع سوار أو نشرًا فيه. يجب أن يمرر المضيف UUID المدخل الذي يعرضه بالفعل؛ المكوّن لا يقرأ أسماء النباتات من الصفحة ولا يحاول استنتاج المعرّف منها.

## تدفق العرض

1. تُحمّل صفحة المضيف ملف المكوّن مرة واحدة.
2. بعد ظهور نتيجة النبات من الباك إند، يُمرر UUID الأصلي إلى `setPlant` أو السمة `uuid`.
3. يجلب المكوّن ملف هذا UUID وحدود المناطق المشتركة. لا يحتاج إلى فهرس البحث.
4. يُغلق دليل النبات السابق ويُزال تظليله فور تغيير المعرّف. الاستجابة المتأخرة لطلب أقدم لا تستبدل النبات الحالي.
5. تفتح المنطقة بطاقة مراجعها بالمرور أو التركيز أو الضغط. يتاح الوصول نفسه من أزرار بأسماء المناطق.

الحقول في ملفات هذه الحزمة هي `uuid` و`senseId`. اسم الحقل المقابل في استجابة سوار يجب تأكيده عند تعديل المضيف؛ لا يفترض هذا المستودع أن اسمًا عامًا مثل `id` أو `_id` يحمل القيمة نفسها. المطلوب **القيمة الأصلية المطابقة**، لا توليد UUID جديد أو بناء جدول ربط بالأسماء العربية.

## مثال قابل للدمج

انشر ناتج `npm run build` تحت مسار مستقل مثل `/flora/`، مع إبقاء الملفات التابعة في مكانها:

```html
<script type="module" src="/flora/assets/flora-map.js"></script>
<saudi-flora-map id="plant-distribution"></saudi-flora-map>
```

في نقطة تحديث بطاقة النبات داخل تطبيق المضيف:

```js
async function displayPlantDistribution(uuid, senseId = null) {
  await customElements.whenDefined('saudi-flora-map')
  document.getElementById('plant-distribution').setPlant(uuid, senseId)
}

// مثال من البيانات الحالية:
displayPlantDistribution(
  'f009a176-94e3-4387-b682-0f416bf31afd',
  '68fa181e1bb5ac220afcfd5e'
)
```

هذا اسم دالة مثال، وليس API موجودًا في سوار. يستدعيه المضيف عندما يغيّر النتيجة المعروضة. عند مسح النتيجة:

```js
document.getElementById('plant-distribution').setPlant(null)
```

## الواجهة

| المدخل أو الحدث | المعنى |
| --- | --- |
| `uuid` / `.uuid` | UUID الأصلي؛ المطابقة دقيقة ولا يُحوّل المكوّن حالة حروفه. |
| `sense-id` | معرّف معنى اختياري. الاختلاف يترك الخريطة بلا تظليل ويعرض رسالة. |
| `.setPlant(uuid, senseId = null)` | يحدّث هوية النبات والمعنى معًا. يمسح معنى النبات السابق عند عدم تمريره. |
| `data-base-url` | رابط مجلد البيانات، ويفضل أن يكون مطلقًا مع `/` أخيرة. الافتراضي مجلد `data/` المجاور لمجلد `assets/`. |
| `local-preview` | اشتراك صريح في تعديلات هذا المتصفح؛ يستخدم في المعاينة والإدارة فقط. |
| `.refresh()` | يعيد حساب العرض الحالي من إصدار البيانات المحمّل والتعديلات المحلية المسموح بها. لا يتجاوز ذاكرة التخزين المؤقت للإصدار نفسه. |
| `flora-map:state` | حدث يتجاوز Shadow DOM، ويحمل `detail: { uuid, state }`. الحالات المرسلة: `ready` أو `empty` أو `unknown_uuid` أو `sense_mismatch` أو `error`. |

غياب UUID يعرض طلب اختيار نبات وخريطة محايدة؛ لا يُرسل حدث `ready`. هذا الحدث ليس بديلًا عن حالة نجاح بحث سوار؛ هو حالة عرض الخريطة وحدها.

مثال متابعة الحالة، إذا احتاجها المضيف:

```js
document.getElementById('plant-distribution')
  .addEventListener('flora-map:state', event => {
    const { uuid, state } = event.detail
    // حدّث حالة مكوّن الخريطة في المضيف عند الحاجة.
  })
```

## الملفات والتحميل

- يلزم الاحتفاظ بجميع ملفات `dist/assets/` التابعة للمدخل، والخطوط، و`dist/data/`. نقل `flora-map.js` منفردًا يكسر الروابط النسبية.
- تتشارك نسخ المكوّن طلب الحدود والطلبات الجارية. الذاكرة تحتفظ بحد أقصى 48 ملف نبات ناجح؛ الطلبات الفاشلة لا تمنع إعادة المحاولة.
- الرسم SVG واحد لكل نسخة. تغيير النبات يغيّر حالته دون إنشاء iframe أو إعادة بناء كل هندسة المناطق.
- CSS المكوّن داخل Shadow DOM. يوجد تعريف مشترك واحد لوجهي خط IBM Plex Sans Arabic. يتوافر بديل نظامي إذا تعذر الخط.
- لا يجلب المكوّن كتاب Excel أو قارئه أو فهرس جميع النباتات عند عرض UUID. هذه الأصول تخص الإدارة أو البحث عند الطلب.
- لا يُنسخ JSON البحث الخام إلى ملفات النشر.

لم تُقَس استجابة الشبكة أو معدل الإطارات في متصفح بهذه البيئة. أحجام الأصول في [تقرير التحقق](verification.md) قياسات ملفات، وليست وعدًا بزمن استجابة.

## إصدار بيانات جديد

لتغيير إصدار البيانات دون إعادة بناء واجهة الخريطة، انشر مجلد البيانات الناتج من أداة الإصدار تحت رابط جديد، مثل:

```html
<saudi-flora-map
  uuid="f009a176-94e3-4387-b682-0f416bf31afd"
  data-base-url="https://example.org/flora/releases/2.0.1/">
</saudi-flora-map>
```

الرابط مثال توضيحي ولم يُنشر. تغيير `data-base-url` يفصل مفاتيح التخزين المؤقت ويحمّل الإصدار الجديد. الأفضل اعتماد رابط إصدار ثابت المحتوى، وتحويل المضيف إلى الإصدار المعتمد. الاستعادة تكون بإرجاع الرابط إلى الإصدار السابق. إذا أُعيد استخدام الرابط نفسه يجب إعادة تحميل الصفحة وضبط تخزين HTTP من جهة النشر.

انقل الإصدار كاملًا: الفهرس، جميع ملفات UUID، الحدود والترخيص وبيان الإصدار. لا تنقل الملفات المعدلة وحدها بينما يبقى الفهرس أو رقم الإصدار قديمًا. صفحة الإدارة القياسية تقرأ `data/` المجاور لها؛ راجع [خطوات Excel والإصدار](excel-workflow.md) لتحديث نسخة الإدارة أيضًا.

## التوافق مع المضيف

يُفضّل مسار مستقل على الأصل نفسه لتبسيط تحميل البيانات والخطوط. عند الاستضافة على أصل آخر، يلزم أن تسمح إعدادات CORS بتحميل JavaScript والبيانات والخطوط، وأن تتوافق `script-src` و`connect-src` و`font-src` وسياسة أنماط Shadow DOM مع سياسة CSP الفعلية للمضيف. هذه الإعدادات لم تُختبر داخل سوار؛ لا تغيّر السياسة الإنتاجية تلقائيًا لإمرار المكوّن.

لا توجد آلية كتابة عامة إلى الخادم. صفحة الإدارة تعمل محليًا وتصدر ملف التغييرات؛ نقل الإصدار المشترك جزء من نشر الملفات المعتمد. صفحة المعجم لا تحتاج إلى عرض أزرار الإدارة أو تفعيل `local-preview`.

## حالات لا يجوز تجاوزها

- UUID مجهول أو معنى غير مطابق: لا تُعرض خريطة نبات آخر.
- هوية نبات محجوبة أو تصنيف يحتاج مراجعة: لا يكفي استيراد صف `verified` لفتحها.
- مكان نصي دون إسناد إداري موثق: يبقى مع مرجعه بلا تلوين تخميني.
- مرجع قيد المراجعة `pending`: محفوظ لكنه لا يلوّن منطقة.
- فشل تحميل الحدود أو البيانات: رسالة وإعادة محاولة؛ ليس حكمًا بغياب النبات.

## القبول قبل الدمج الإنتاجي

على بيئة متصفح متاحة، شغّل `npm run test:browser` وراجع يدويًا اختيار نباتين متشابهَي الاسم، تغيّر UUID سريعًا، منطقة صغيرة على الجوال، الوصول إلى رابط المصدر من لوحة المفاتيح، إغلاق البطاقة، التكبير، قارئ الشاشة العربي، وأثر CSS وCSP الفعليين. لم تُنفّذ هذه المراجعة داخل سوار في هذا التعديل.

مراجع التصميم التقني: [MDN: دورة حياة Custom Elements](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements)، [W3C: المحتوى عند المرور أو التركيز](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html). مواصفات الهوية والأدلة الخاصة بالمشروع موثقة في [خطة التنفيذ](uuid-map-plan.md) و[تقرير البيانات](data-build-report.json).
